          Sources & réglages (polis)

          Uniquement APIs/RSS officiels + tes flux. Pas de contournement anti-bot, pas de scrape LinkedIn/X. Throttle + cache pour rester dans les quotas gratuits.

          Pourquoi API/RSS plutôt que scrape

          • RemoteOK, Remotive, Arbeitnow, Jobicy, Himalayas, WWR RSS = officiels.
          • X/Twitter & LinkedIn : pas de scrape AscendOS — colle un RSS que toi héberges.
          • Throttle local + cache = pas de ban pour abus de quota gratuit.
          • Remotive / Himalayas peuvent être ~24h de retard : le badge fraîcheur le reflète.
